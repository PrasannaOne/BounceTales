# V42: Single-screen touch editor

The touch-control editor is now compact and non-scrollable. Its title, four control selectors, size slider, note, and Reset / Cancel / Save actions are kept within the visible viewport, with tighter sizing on short screens. The overlay remains pointer-transparent outside the panel so the actual gameplay controls can still be dragged while editing.

The game runtime and level data are unchanged. Asset and service-worker cache versions are bumped to V42.
